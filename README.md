📖 Sobre o Projeto
O Zingen é uma landing page desenvolvida para apresentar um aplicativo de karaokê com foco em design moderno, experiência do usuário e conversão.

A página foi construída utilizando apenas tecnologias front-end, com uma estrutura responsiva e animações suaves para proporcionar uma navegação agradável em diferentes dispositivos.

✨ Funcionalidades
✅ Layout moderno e responsivo
✅ Seção Hero com destaque principal
✅ Apresentação dos recursos do aplicativo
✅ Área de preços e planos
✅ Seção de download do aplicativo
✅ Navegação intuitiva
✅ Efeitos visuais e transições suaves
✅ Compatível com dispositivos móveis

🚀 Como Executar o Projeto
1. Clonar o repositório
git clone https://github.com/noslerom/5-Zingen.git
2. Entrar na pasta
cd 5-Zingen
3. Abrir com Live Server
No VS Code:

Clique com o botão direito em index.html
Selecione Open with Live Server
Ou utilize qualquer servidor local de sua preferência.
